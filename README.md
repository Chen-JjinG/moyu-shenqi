# 诊断工具

一个看起来像工作软件的轻量 Windows 桌面窗口。外壳是 Visual Studio「诊断工具」，也可以换成 Visual Studio Code、IntelliJ IDEA，或一个「搜狗每日新词」样式的弹窗。网页视图不铺满窗口：诊断工具主题里，它嵌在「进程内存 (MB)」波形图内部，和曲线叠在一起；每日新词主题里，它只占左侧「夜明砂」那一张大图。这块区域里仍然可以用鼠标和键盘正常浏览。

程序不会登录账号，也不会自己往外发数据。除了你打开的网页，没有别的网络请求。浏览记录和主题只存在这台电脑上。

## 下载可以直接用的程序

源码在 GitHub 之后，Actions 会在 Windows 上打出一个单文件：

1. 打开仓库的 **Actions** 或 **Releases**。
2. 下载 `DiagnosticTools.exe`。
3. 双击运行。

Windows 10 / 11 一般已经装了 WebView2。如果双击没反应，或提示缺少 WebView2，再运行同一个产物里的 `DiagnosticTools_0.1.0_x64-setup.exe`。这是一个安装包，会补上运行库，并在开始菜单放一个快捷方式。不需要把一文件夹文件解出来才能用。

## 本机自己编译（Windows）

先装好这三样：

- [Node.js 22](https://nodejs.org/)（20 也可以）
- [Rust stable](https://rustup.rs/)（安装时选默认工具链）
- Visual Studio 生成工具 2022，勾选「使用 C++ 的桌面开发」（Tauri 需要 MSVC 链接器）

WebView2 运行时：Windows 11 和更新过的 Windows 10 通常已经有。没有的话，安装包会在第一次安装时下载。

在仓库根目录执行：

```bat
npm install
npm run build:win
```

两条都成功之后：

- 绿色单文件：`src-tauri\target\release\DiagnosticTools.exe`（拷走这一个 exe 就能在有 WebView2 的电脑上运行）
- 安装包：`src-tauri\target\release\bundle\nsis\DiagnosticTools_0.1.0_x64-setup.exe`

开发时边改边看：

```bat
npm install
npm run dev:app
```

## 怎么用

窗口初次打开是空的诊断面板，不会自动打开上次的网页。

| 操作 | 做法 |
| --- | --- |
| 打开地址 | `Ctrl+L`，或标题栏齿轮 /「···」/「▾」里的「打开…」 |
| 后退、前进 | `Alt+←` / `Alt+→`，菜单里叫「向后导航 / 向前导航」 |
| 刷新 | `F5` 或 `Ctrl+R` |
| 置顶并固定位置 | 标题栏图钉，或 `Ctrl+Shift+T`。再按一次取消。置顶后窗口保持在最前，标题栏不能拖走 |
| 整窗缩放 | `Ctrl++`、`Ctrl+-`、`Ctrl+0` 恢复 100%。菜单「界面缩放」里也有 80%–200% |
| 换外观 | 菜单「外观」：诊断工具、Visual Studio Code、IntelliJ IDEA、每日新词 |
| 立刻藏起网页 | Ctrl 加反引号，或 Ctrl+Shift+H。诊断工具主题只留下原来的内存图和下面的「尚无可用快照」；每日新词主题的大图恢复成静态的「夜明砂」 |
| 记住当前页 | 诊断工具主题里的「截取快照」。之后「查看堆」可以双击打开 |
| 关闭 | 标题栏 ✕ |

诊断工具主题顶部的内存和 CPU 图每秒动一次，只是看起来像正在采样。工具栏上的放大镜缩放的是这条时间轴，不是网页。整窗缩放才是把外壳和页面一起变大。

IDE 主题里，网页会被压成偏蓝灰的深色，避免一打开就是彩色网站，页面仍在编辑区。诊断工具主题同样套这层颜色，但页面只出现在「进程内存 (MB)」的绘图区里，和钢蓝色填充、波形、黄色 GC 标记叠在同一块；标题、事件轨、CPU、标签和下面的快照区都还在。波形画在页面上面，点击会透过去，页面可以滚动、点选和输入。每日新词主题不套这层颜色，页面只嵌在左侧那张大图里，标题栏、右上角沪江网校 / 9元敞开学、旁边的文字、下面的列表和「不再提示」都保持可见。

滤镜是网页视图上的一层合成，个别网站的吸顶栏会跟着页面滚动。文本和按钮仍然可以点、可以输入。

## 主题

- **诊断工具**：对齐 Visual Studio 深色「诊断工具」的标题、工具栏、会话计时、事件轨、进程内存、CPU、摘要/事件/内存/CPU 标签，以及「截取快照」「查看堆」。打开网页以后，页面藏在「进程内存 (MB)」波形图内部，不挡住其余外壳。没打开网页或按了隐藏热键时，这里只是原来的内存图。
- **Visual Studio Code**：活动栏、资源管理器和编辑器标签。没打开网页时显示一段 C#。
- **IntelliJ IDEA**：新 UI 深色，左侧项目树，没打开网页时显示一段 Java。
- **每日新词**：浅色小弹窗，标题是「搜狗每日新词」，右上角是沪江网校 / 9元敞开学和吉祥物，底部有「不再提示」。网页只显示在左侧「夜明砂」大图的位置；没打开网页，或按了隐藏热键时，那里恢复成静态书法画面。

「不再提示」只记住勾选状态，不会把程序关掉。想退出用右上角 ✕。

## 隐私

- 没有账号，没有统计，没有自动更新。
- 快照列表、主题、缩放、窗口大小写在本机 `localStorage`。
- 网页的 Cookie 由系统 WebView2 存在本机用户目录，只供你下次打开同一站点。
